# DeFlock Lewis County

Website for the grassroots effort opposing Flock license plate readers in Lewis County, New York.

**They track every driver. Not just criminals.**

## About

A Flock license plate reader is already up in Lewis County — logging the plate, make, model, and color of every car that passes. This site shares what these cameras do and organizes residents around the rally outside the Board of Legislators meeting:

- 📅 Tuesday, August 4 · 4:30 PM
- 📍 Lewis County Court House, 7660 N State St, Lowville

## Development

The site is a single self-contained `index.html` — no build step, no dependencies. Open it in a browser to preview.

## Deploying with GitHub Pages

1. In the repo, go to **Settings → Pages**
2. Under **Source**, select **Deploy from a branch**
3. Choose the branch and `/ (root)` folder, then save

The site will be published at `https://<username>.github.io/deflocklewis/`.
